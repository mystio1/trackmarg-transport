# Security Policy

## Reporting a Vulnerability

If you discover a security vulnerability in Transport Manager, please report it responsibly.

**Email:** trackmarg@gmail.com

Please include:
- A description of the vulnerability
- Steps to reproduce the issue
- Any potential impact

We will acknowledge receipt within 48 hours and aim to provide a fix within 7 days for critical issues.

## Supported Versions

| Version | Supported |
| ------- | --------- |
| Latest (main branch) | ✅ |

## Scope

This policy covers the Transport Manager application deployed at the production URL and the source code in this repository.
